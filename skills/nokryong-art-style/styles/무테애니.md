# 무테 애니

## 1. 화풍 정체성
- 중간 수준의 데포르메를 사용한 손그림 느낌의 일본 만화 일러스트.
- 선 대신 색면의 모양과 경계로 완성도 있는 형태와 세부 표현을 만든다.

## 2. 형태와 데포르메
- 얼굴의 인상과 표정, 자연스러운 몸짓과 의상 구조를 유지한다.
- 머리카락은 여러 개의 응집된 덩어리와 겹치는 층으로 구성하고, 필요한 앞머리·옆머리 형태를 살린다.

## 3. 선과 경계
- 외곽선과 내부 펜선을 사용하지 않는다.
- 얼굴 요소, 머리카락의 층, 옷의 절개와 주요 주름, 신체와 물체의 겹침을 서로 맞닿는 색면 경계로 선명하게 구분한다.

## 4. 색과 명암
- 평면 채색과 재질별 명확히 구분되는 그림자 한 단계만 사용한다.
- 인물과 배경의 명암·드리운 그림자·하이라이트는 모두 경계가 뚜렷한 셀 색면으로 표현한다.
- 머리카락·피부·의상은 대체로 무광이며, 하이라이트는 작고 드물게 넣는다.

## 5. 묘사 밀도와 배경
- 무테 표현을 이유로 눈·얼굴·의상 디테일을 삭제하거나 모든 형태를 단순한 도형으로 축소하지 않는다.
- 개별 머리카락과 불필요한 잔주름은 줄이고, 배경은 장면을 알아볼 수 있는 주요 형태와 필수 오브젝트로 구성한다.

## 6. 적용 원칙
- 요청한 캐릭터와 장면을 따르며, 이 문서는 무테 조형과 색면 표현 방식을 정의한다.
