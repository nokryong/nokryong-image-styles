# 아마추어 웹툰

## 1. 화풍 정체성

- 온라인 커뮤니티에 취미로 올리는 듯한 소박한 일본풍 아마추어 웹툰.
- 가볍고 자연스러운 디지털 손그림 느낌. 간결하지만 완성된 그림으로 표현한다.

## 2. 형태와 데포르메

- 중간 수준의 데포르메. 적당히 큰 머리, 작은 얼굴 하부, 약간 짧은 몸통과 팔다리.
- 단순하고 친근한 만화풍 얼굴. 캐릭터마다 고유한 인상과 표정을 살린다.
- 머리카락은 크고 응집된 덩어리와 단순한 실루엣으로 구성하며, 헤어스타일에 필요한 구분선만 사용한다.
- 신체와 의상은 큰 형태를 중심으로 구성하되 자연스러운 구조와 특징을 유지한다.

## 3. 선화

- 가늘고 선명한 검은색 디지털 펜선을 사용한다.
- 선 굵기는 대체로 일정하되 미세한 변화와 자연스러운 불균일함을 허용한다.
- 표정, 머리카락, 의상, 동작에 필요한 표현선을 사용하되 지나치게 정교하거나 기계적인 선화는 피한다.

## 4. 색과 명암

- 흑백을 기본으로 단 하나의 평면 강조색을 선택적으로 사용한다.
- 어두운 고유색은 검정, 밝은 고유색은 흰색으로 표현하며 강조색은 장면에 맞게 배치한다.
- 입체감을 위한 명암, 하이라이트, 회색조, 그라데이션, 스크린톤, 복잡한 질감은 사용하지 않는다.

## 5. 묘사 밀도와 배경

- 전체 묘사는 간결하게 유지하되 캐릭터의 개성, 주요 의상 특징, 자연스러운 주름과 몸짓은 살린다.
- 개별 머리카락, 세밀한 질감, 반복적인 잔선 묘사는 줄인다.
- 배경은 장소를 알아볼 수 있는 단순한 구조와 필요한 소품으로 구성한다.
- 불필요한 장식과 반복적인 세부 묘사를 피한다.

## 6. 적용 원칙

- 요청한 캐릭터, 의상, 표정, 행동, 구도, 배경을 따른다.
- 참고 자료는 캐릭터의 정체성을, 이 문서는 그림체를 정의한다.
- 기본적으로 완성된 웹툰 장면 하나를 제작하며, 글자는 요청한 경우에만 추가한다.
